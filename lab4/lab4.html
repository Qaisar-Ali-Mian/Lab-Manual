Applying CSS to HTML

There are three ways to apply CSS to an HTML web page.
Inline CSS is written directly inside an HTML element using the style attribute.
Internal CSS is written inside the style tag in the head section of the HTML page.
External CSS is written in a separate CSS file and linked to the HTML document.
External CSS is commonly used because it keeps code organized and reusable.

Internal CSS Example

Internal CSS is written inside the style tag in the head section of an HTML document.
It is useful for applying styles to a single webpage and helps keep the design organized.
