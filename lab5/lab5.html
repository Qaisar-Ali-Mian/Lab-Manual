Experiment 5: CSS Selectors

In this experiment, we explore different types of CSS selectors used to style HTML elements. These include element, class, ID, grouping, descendant, child, attribute, pseudo-class, and pseudo-element selectors. The purpose is to understand how each selector targets specific elements in a webpage and how they help in applying precise and efficient styling to improve webpage design and structure.

Element Selector

The element selector styles all elements of a specific type, such as all headings or paragraphs, on a webpage.

ID Selector (#id)

It styles a single unique element using an ID selector like #idName.

Grouping Selector

It applies the same style to multiple elements at once like h1, p, ul.

Descendant Selector

It styles elements inside another element like div p (all p inside div).

Child Selector

It styles only direct child elements using > symbol like div > p.

Attribute Selector

It styles elements based on attributes like input[type="text"].

Pseudo-class Selector

It styles elements in special states like hover, first-child, last-child.

Pseudo-element Selector

It styles specific parts of an element like first letter or before/after content.
